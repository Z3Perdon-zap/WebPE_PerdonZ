# WebPE_PerdonZ

A profile card website that fetches row 2 (Jane Doe) of the Google Sheet through the Google Sheets API and displays it in a card with a light/dark mode toggle.

## How to run

1. Make sure your device is connected to a stable internet connection, since the data is fetched from Google Sheets.
2. Perform either of the following to run the code:

   - **Option A:** double-click the `index.html` file.
   - **Option B:** right-click the `index.html` file, click **Open With**, and select a browser of your choosing.

Keep `index.html`, `style.css` and `script.js` in the same folder.
